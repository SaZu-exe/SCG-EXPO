# CAMPAR SGC Digital v0.5

Prototipo estático para GitHub Pages. Esta versión está enfocada en consulta ejecutiva y reuniones con Planta.

## Novedades
- Modo reunión por planta, de sólo consulta.
- Buscador global por OC, producto, lote, inspección y NC.
- Expediente único por OC con pestañas de resumen, producción, inspecciones, entregas, evidencia e historial.
- Resumen imprimible de cada OC.
- Acceso rápido al Manual de Calidad y al Compendio Maestro durante una reunión.
- Mantiene el flujo de producción: En corte → En armado → En estufado → Limpios.
- Mantiene Cosme = MX-1361 y Duma = MX-1071.

## Publicación
Sube el contenido completo de esta carpeta a la raíz del repositorio de GitHub Pages, conservando `assets/` y `docs/`.

## Nota
Es un prototipo sin backend. Los archivos operativos externos (por ejemplo constancias HT o acuses de recepción) se muestran como pendientes cuando no existe un archivo real vinculado; no se simula evidencia inexistente.
